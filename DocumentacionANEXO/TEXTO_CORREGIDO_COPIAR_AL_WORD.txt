La arquitectura tecnológica implementada —React.js con Vite como framework de frontend, Node.js con Express como servidor de backend, Sequelize como ORM, PostgreSQL 16 como sistema gestor de base de datos relacional y despliegue en servidor VPS con Ubuntu Server 24.04 LTS— sigue las mejores prácticas de la industria del desarrollo de software moderno y garantiza la estabilidad, seguridad y mantenibilidad del sistema. Se integran, además, tecnologías complementarias como Framer Motion para animaciones de interfaz, Nodemailer para el envío de correos electrónicos de recuperación de contraseña, y JSON Web Tokens (JWT) junto con bcryptjs para la autenticación segura de usuarios con cifrado de contraseñas. El sistema también incorpora autenticación federada mediante Google OAuth 2.0, permitiendo a los usuarios iniciar sesión con su cuenta institucional de Google. Esta elección tecnológica, basada en el ecosistema JavaScript full-stack, permite que el sistema pueda ser actualizado y ampliado por futuros equipos de desarrollo sin requerir migraciones tecnológicas costosas, al estar construido íntegramente sobre estándares web abiertos y ampliamente documentados.

9.2 Descripción del Sistema Web Desarrollado

El sistema web de concientización sobre Ingeniería Social, denominado PhishGuard UTB, fue desarrollado e implementado como una plataforma de aprendizaje progresivo y autónomo, accesible desde cualquier dispositivo con conexión a internet. A continuación se describen las funcionalidades implementadas, organizadas por rol de usuario.

Funcionalidades del Estudiante

Módulo de registro e inicio de sesión. El sistema permite a los estudiantes crear una cuenta personal proporcionando nombre, apellido, correo electrónico, contraseña, semestre que cursa, género y si utiliza correo institucional UTB. La autenticación se implementó mediante JSON Web Tokens (JWT) con contraseñas cifradas con bcryptjs utilizando sal de 10 rondas. Adicionalmente, se implementó inicio de sesión con Google OAuth 2.0, permitiendo el acceso directo con cuentas institucionales, así como un sistema completo de recuperación de contraseña por correo electrónico mediante Nodemailer, con tokens criptográficos de un solo uso y expiración de 1 hora.

Encuesta diagnóstica inicial. Una vez registrado, el estudiante debe completar una encuesta diagnóstica estructurada compuesta por 8 preguntas cerradas de opción múltiple, que evalúa su nivel de conocimiento previo sobre las principales técnicas de Ingeniería Social (phishing, pretexting, vishing y baiting), así como su percepción de vulnerabilidad y su interés por herramientas educativas digitales. El sistema clasifica automáticamente al estudiante en nivel bajo, medio o alto según sus respuestas, y registra los resultados para su posterior análisis estadístico por parte del administrador. Esta encuesta es requisito previo para acceder al contenido educativo de la plataforma.

Módulo de aprendizaje con contenido interactivo. El contenido educativo se organizó en cuatro unidades temáticas, cada una con entre 5 y 7 secciones de aprendizaje progresivo:

Módulo 1 — Phishing (7 secciones): Abarca la definición y clasificación de ataques de phishing (spear phishing, smishing, clone phishing), una simulación visual de correo electrónico fraudulento con señales de alerta destacadas, medidas de protección específicas, un caso real documentado de ataque de tipo Business Email Compromise (BEC) que causó pérdidas por 2.3 millones de dólares, y un laboratorio interactivo de detección donde el estudiante analiza y compara correos legítimos con fraudulentos.

Módulo 2 — Pretexting (6 secciones): Incluye los fundamentos de la técnica de pretexting, un escenario simulado de suplantación de identidad ambientado en un entorno universitario, medidas de protección, un caso real de fraude por soporte técnico falso dirigido a estudiantes universitarios latinoamericanos (2022-2023), y una clasificación detallada de las identidades falsas más frecuentemente utilizadas por atacantes (figuras de autoridad, colegas, soporte técnico, investigadores).

Módulo 3 — Vishing (5 secciones): Presenta la definición de vishing y sus variantes, una simulación de llamada telefónica fraudulenta con análisis de la conversación, medidas de protección, un análisis técnico de las técnicas de manipulación vocal (caller ID spoofing, deepfake de voz, ingeniería del pánico, presión temporal, personalización con datos reales), y una simulación interactiva de respuesta correcta ante un intento de vishing bancario.

Módulo 4 — Baiting (5 secciones): Comprende la definición y tipos de baiting (físico y digital), un escenario simulado de USB infectada en campus universitario, medidas de protección, una clasificación de las trampas digitales más comunes (software crackeado, streaming ilegal, premios falsos, apps falsas, cables trampa), y un caso real basado en el experimento de la Universidad de Illinois (Tischer et al., 2016) donde el 45% de las personas conectaron dispositivos USB desconocidos a sus computadoras.

Cada sección incluye contenido didáctico con formato enriquecido (negritas, listas, simulaciones visuales de correos electrónicos y mensajes SMS), iconografía ilustrativa profesional y señales de alerta claramente identificadas.

Módulo de evaluación mediante Quiz interactivo. Cada unidad temática incluye un cuestionario de evaluación compuesto por 10 preguntas de opción múltiple, con retroalimentación inmediata y explicativa por cada pregunta respondida. El sistema calcula automáticamente la calificación obtenida, requiere una nota mínima de 7 sobre 10 (70%) para considerar el módulo como aprobado, y permite reintentos ilimitados para que el estudiante alcance la nota aprobatoria. Los resultados de cada intento se almacenan automáticamente en la base de datos para su análisis posterior.

Panel de progreso del estudiante. La plataforma presenta un panel de progreso personalizado que muestra al estudiante un resumen visual de su avance académico mediante tarjetas estadísticas (módulos completados, promedio general, quizzes realizados), barras de progreso por módulo con indicadores de porcentaje, estado de completitud por módulo (completado, en progreso, pendiente) y el progreso general expresado como porcentaje del programa total completado.

Sistema de logros y gamificación. Se implementó un sistema de gamificación que otorga insignias o logros automáticos al estudiante al alcanzar hitos específicos dentro de la plataforma, tales como: completar la encuesta diagnóstica, aprobar el primer quiz, completar todos los módulos con nota aprobatoria, entre otros. Los logros se presentan con iconografía visual distintiva y la fecha de obtención, incentivando la participación activa del estudiante.

Generación de certificado digital. Al completar los cuatro módulos con nota aprobatoria (≥7/10 en cada quiz), el sistema genera automáticamente un certificado digital personalizado con el nombre completo del estudiante, la fecha de emisión, un código de verificación único y los logotipos institucionales de la UTB y la FAFI. Este certificado puede ser descargado por el estudiante como constancia de su capacitación en concientización sobre Ingeniería Social.

Sistema de notificaciones. El estudiante recibe notificaciones en tiempo real mediante un ícono de campana ubicado en la barra de navegación, informándole sobre eventos relevantes como: mensaje de bienvenida al registrarse, logros desbloqueados, módulos completados exitosamente y disponibilidad de su certificado digital.

Perfil de usuario. Sección accesible desde la barra de navegación mediante el nombre y avatar del usuario, donde el estudiante puede visualizar y editar sus datos personales, incluyendo nombre, apellido, semestre, género y uso de correo institucional.

Modo oscuro. Se implementó un toggle de tema (claro/oscuro) accesible en la interfaz de usuario que modifica el esquema de colores completo de la plataforma a un tema oscuro, mejorando la experiencia de uso en condiciones de baja iluminación, reduciendo la fatiga visual y adaptándose a las preferencias del usuario.


Funcionalidades del Administrador

Dashboard administrativo. Panel de control con tarjetas estadísticas interactivas que presentan métricas clave del sistema: número de estudiantes registrados, estudiantes activos (con acceso en los últimos 30 días), encuestas diagnósticas completadas, certificados emitidos, total de quizzes realizados y tasa de aprobación general. Cada tarjeta es interactiva y redirige al administrador a la sección correspondiente para un análisis detallado.

Gestión de módulos y contenidos (CRUD completo). El administrador cuenta con una interfaz de gestión para crear, editar, reordenar y eliminar módulos educativos y sus respectivos contenidos. El editor de contenido soporta texto enriquecido con formato visual (negritas, cursivas), selección de tipo de contenido (texto explicativo, video, imagen, ejemplo interactivo, caso real) e inserción de enlaces a recursos externos y archivos multimedia.

Gestión de preguntas de evaluación (CRUD completo). Interfaz dedicada para administrar las preguntas de cada cuestionario de evaluación, incluyendo la definición de opciones de respuesta, selección de la respuesta correcta y redacción de la retroalimentación explicativa personalizada que el estudiante recibe al responder.

Gestión de estudiantes. Listado completo de estudiantes registrados en la plataforma con sus datos de perfil, estado de cuenta (activo/inactivo), fecha de último acceso y acciones administrativas disponibles (activar/desactivar cuenta).

Panel de estadísticas. Visualización de métricas agregadas del sistema que incluyen la distribución de niveles de conocimiento según la encuesta diagnóstica, el progreso general de los estudiantes por módulo, las tasas de aprobación por unidad temática y las estadísticas de uso de la plataforma.

Anexo B: Arquitectura del Sistema Web Implementado

El sistema web PhishGuard UTB fue implementado siguiendo una arquitectura de tres capas, ampliamente utilizada en el desarrollo de aplicaciones web modernas:

Capa de presentación (Frontend): Desarrollada con React.js 19 y compilada con Vite 8, esta capa gestiona la interfaz de usuario mediante componentes reutilizables y reactivos. Se utilizó React Router DOM 7 para la navegación tipo SPA (Single Page Application) con rutas protegidas por rol de usuario, Framer Motion para animaciones fluidas de interfaz, React Icons para iconografía profesional SVG, React Hot Toast para notificaciones visuales al usuario, y @react-oauth/google para la integración con Google OAuth 2.0. El diseño es completamente responsivo, adaptándose a dispositivos móviles, tablets y computadoras de escritorio, e incluye un modo oscuro completo con persistencia de la preferencia del usuario mediante clases CSS dinámicas.

Capa de lógica de negocio (Backend): Implementada con Node.js 22 LTS y Express 4, esta capa procesa las solicitudes del frontend a través de una API RESTful organizada en 11 grupos de rutas: autenticación (registro, login, Google OAuth, recuperación de contraseña), módulos educativos, quiz y evaluaciones, progreso del estudiante, encuesta diagnóstica, certificados, administración, contenidos, preguntas, logros y notificaciones. La seguridad se implementó mediante múltiples capas: Helmet para la protección de cabeceras HTTP contra ataques XSS y clickjacking, express-rate-limit para la limitación de solicitudes (200 peticiones por 15 minutos como límite general y 20 peticiones por 15 minutos específicamente para endpoints de autenticación), CORS configurado para aceptar solicitudes únicamente desde el dominio del frontend, y autenticación stateless mediante JSON Web Tokens (JWT). La interacción con la base de datos se realiza a través de Sequelize 6 como ORM, con validaciones a nivel de modelo y hooks automáticos para el cifrado de contraseñas. El envío de correos electrónicos transaccionales se gestiona mediante Nodemailer configurado con Gmail App Password, utilizando plantillas HTML profesionales con el diseño institucional de la UTB.

Capa de datos: Gestionada mediante PostgreSQL 16, almacena la información del sistema en un esquema relacional compuesto por 11 tablas: usuarios (con campos para autenticación, perfil y recuperación de contraseña), módulos educativos, contenidos, preguntas de evaluación, resultados de quizzes, progreso por módulo, encuestas diagnósticas, certificados, logros, logros por usuario (tabla pivote N:M) y notificaciones. Las relaciones entre tablas (1:N y N:M) están definidas mediante Sequelize, con integridad referencial garantizada por claves foráneas, validaciones de datos a nivel de modelo y hooks para el procesamiento automático previo a la creación y actualización de registros.

Infraestructura de despliegue: El sistema fue desplegado en un servidor VPS (Virtual Private Server) con Ubuntu Server 24.04 LTS como sistema operativo. Nginx 1.24 actúa como servidor web y proxy inverso, redirigiendo las solicitudes HTTPS al proceso Node.js que ejecuta la API del backend. Se implementó un certificado SSL gratuito de Let's Encrypt mediante Certbot para garantizar la comunicación cifrada entre el navegador del usuario y el servidor. PM2 administra el proceso Node.js en producción, proporcionando reinicio automático ante fallos, monitoreo de recursos del sistema y gestión de logs. El frontend compilado por Vite se sirve como archivos estáticos desde Nginx. El código fuente se gestiona en un repositorio privado de GitHub, y el despliegue se realiza mediante operaciones git pull seguidas de recompilación del frontend y reinicio del servicio backend.
